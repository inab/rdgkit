# Contributing to the Research Data Governance Kit

Thank you for your interest in contributing to this project! This kit is a collaborative effort to build a robust knowledge base for Research Data Governance, and your expertise is highly valuable.

By contributing to this repository, you agree that your contributions will be licensed under the project's multi-licensing model ([CC BY 4.0](LICENSE) for documentation, [CC0 1.0](LICENSE) for datasets/templates, and [MIT](LICENSE) for code).

---

## 🗺️ How Can I Contribute?

### 1. Proposing New Use Cases or FAQs
If you want to add a new question, challenge, or governance scenario:
1. **Check existing issues/files** to ensure the topic hasn't been covered yet.
2. **Open an Issue** using the "New FAQ/Use Case Request" template (or just describe the governance problem clearly).
3. Alternatively, you can directly submit a **Pull Request (PR)** with the proposed content.

### 2. Reviewing and Improving Content
Data governance regulations and best practices change constantly. You can help by:
* Updating outdated compliance information (e.g., GDPR, local institutional policies, funder mandates).
* Fixing typos, improving clarity, or translating content.

---

## 🚀 Pull Request Process

To maintain a clean history and high-quality content, please follow these steps:

1. **Fork the repository** and create your branch from `main` (e.g., `feature/new-faq-funder-mandate`).
2. If you are adding a new file or modifying existing text, ensure it adheres to the repository's tone (neutral, practical, and clear).
3. **Update the documentation** if your change requires it.
4. Submit the Pull Request referencing any related issues (e.g., `Closes #12`).
5. A maintainer will review your PR, suggest edits if necessary, and merge it.

---

## 👥 Authorship and Credit Policy

We believe in giving proper credit to every contributor. When your first substantive content contribution (such as a new FAQ, case study, or major revision) is merged:

1. **`AUTHORS.md`:** You will be added to the Individual Authors list along with your institution.
2. **`CITATION.cff`:** Your name, affiliation, and ORCID (optional) will be added to the metadata file so that future academic citations of this Kit automatically include you as a co-author.

*Note: If you submit a PR, feel free to add your details to `AUTHORS.md` and `CITATION.cff` as part of your pull request!*

---

## 📜 Code of Conduct

We expect all contributors to adhere to a respectful, inclusive, and professional behavior in all interactions within this repository (Issues, Pull Requests, and discussions). 

Be constructive when reviewing others' work—we are all here to improve the state of Research Data Governance together.
