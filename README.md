# rdgkit
Research Data Governance Toolkit - Space to find the answers to your research data governance questions.

## Local Development with Docker

Install Docker with Docker Compose (Docker Desktop on macOS/Windows, or Docker
Engine with the Compose plugin on Linux). On Windows, use a WSL2 workspace.
No host Ruby or Jekyll installation is needed.

From the repository root, launch the preview:

```sh
docker compose up
```

Open <http://localhost:4000>. Changes are picked up automatically with LiveReload
and polling. The first launch builds the image and installs dependencies; later
launches reuse cached layers and the named gem volume.

Stop the preview with:

```sh
docker compose down
```

The gem cache is retained. After changing the Gemfile, run
`docker compose up --build` to refresh the image; startup also installs any gems
missing from the persistent cache. The ignored local lockfile is used when
present and generated by Bundler when absent.

Compose overrides `baseurl` only for the local preview. Docker setup files are
excluded from generated site output; the GitHub Pages deployment workflow is
unchanged.

## Image assets

- `assets/img/favicons/`: browser icons, the web app manifest, and its icons.
- `assets/img/icons/`: UI and topic graphics.
- `assets/img/logos/`: site, partner, and funder logos.

Set the navigation logo with `theme_variables.topnav.brand_logo` in
[`_config.yml`](./_config.yml), and footer images in
[`_data/footer.yml`](./_data/footer.yml). Use Jekyll's `relative_url` filter
for local asset URLs so they work with the site's `baseurl`.

[`_includes/head.html`](./_includes/head.html) overrides the hardcoded favicon
and Open Graph image paths in `elixir-toolkit-theme` 6.1.0. Keep it in sync
with the upstream include when upgrading the theme. Manifest icon paths are
relative to the manifest in `assets/img/favicons/`, so they also work when
the site is deployed under a subpath.
