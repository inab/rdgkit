## Description:
Ensures processing and analysis are secure, traceable, reproducible, and of high quality, with defined roles, policies, controls, and audits.

## Requirements:
* [ ] We have defined whether processing and analysis will be federated or centralized.
* [ ] We have established data processing policies (e.g. sensitive data, purpose of use).
* [ ] We have determined and specified where data is computed (e.g. local, national, European physical facilities) ensuring legal compliance and data security.
* [ ] We have defined data inputs (obtained through ad-hoc repositories or standardized solutions) including programmatic access when possible.
* [ ] We have defined results (outputs): what datasets are generated, where and how they are made available, automation of results, and post-processing quality has been evaluated.
* [ ] We have implemented technical and procedural controls to ensure traceability, integrity, and quality.
* [ ] We have implemented technical control means (e.g. 5-safes, secure environments, authentication, and authorization).
* [ ] We have established audits, risk management plans, and traceability to monitor and detect deviations.
* [ ] We have performed an independent review of results, if necessary.
* [ ] We have defined software requirements necessary for efficient data processing and analysis.
* [ ] We have defined how to share and reuse results derived from analysis.
* [ ] We have documented algorithms, scripts, and analysis pipelines to ensure reproducibility.

## Questions like ...
* Have I defined whether data processing or analysis will be federated or centralized?
* Can responsibles of each processing stage modify data or only consult it?
* Have I defined what sensitive data requires special treatment? Which one?
* Have I established protocols to ensure data is used only for authorized purposes?
* Are there technical control means like 5-safes, secure environments, authentication, and authorization ensuring only authorized personnel can access and process data?
* Has the level of security and data protection in the processing environment been evaluated?
* Do I comply with applicable regulations based on physical data location?
* Has post-processing data quality been evaluated and are incidents or errors recorded?
* Do we record versions and dependencies of scripts, pipelines, and algorithms used in processing?
* Have results been validated or independently reviewed when appropriate?
* How will results be shared and reused?

## Specific practices
* **Practices that should be avoided:** Using governance regulations in a non-standardized manner.
* **Practices that should be standardized:** Using existing governance regulations such as ISO/IEC 38505-1, GDPR, National Security Scheme (ENS), European Health Data Space (EHDS), and Digital Governance Act (DGA).
